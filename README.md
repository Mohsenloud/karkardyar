# کارکردیار (KarkardYar) — سامانه شخصی ثبت کارکرد و حقوق کارگران

وب‌اپلیکیشن سبک، مدرن و واکنش‌گرا (بهینه‌شده برای موبایل) جهت ثبت حضور و غیاب، محاسبه خودکار کارکرد کارگران از تاریخ ورود تا امروز، مدیریت مساعده‌ها و صدور صورت‌حساب PDF و چاپی با دیتابیس **SQLite**.

---

## ویژگی‌های کلیدی
* **محاسبه هوشمند تا امروز:** محاسبه خودکار روزهای کارکرد و دستمزد از تاریخ استخدام تا امروز به همراه نمایش روزهای باقی‌مانده از قرارداد.
* **ویرایش سریع و بدون تاخیر (0ms):** تغییر وضعیت حضور/غیاب در تقویم یا کم و زیاد کردن روزهای کارکرد به‌صورت آنی.
* **مدیریت مساعده و پرداختی‌ها:** ثبت مساعده، تسویه حقوق و کسورات با کسر خودکار از مانده قابل پرداخت.
* **صدور صورت‌حساب موبایلی، چاپی و PDF:** دریافت مستقیم فایل PDF استاندارد فارسی و چاپ تمیز فیش کارکرد هر کارگر.
* **دیتابیس سبک و دائمی SQLite:** ذخیره تمام اطلاعات در یک فایل (`./data/karkard.sqlite`) با قابلیت دانلود فایل پشتیبان (Backup) از داخل برنامه.

---

## راهنمای جامع نصب و راه‌اندازی با Docker روی سرور (VPS)

این راهنما به گونه‌ای تنظیم شده است که اگر روی سرور شما در مسیر `/var/www/app` برنامه دیگری با داکر در حال اجرا باشد، **هیچ‌گونه تداخل پورت، شبکه یا فایلی** با آن ایجاد نشود.

---

### گام ۱: اتصال به سرور و بررسی وضعیت فعلی
ابتدا با SSH به سرور خود متصل شوید و کانتینرهای در حال اجرا را بررسی کنید تا ببینید چه پورت‌هایی اشغال شده‌اند:

```bash
docker ps
```
> **نکته:** این برنامه به‌صورت پیش‌فرض در فایل `docker-compose.yml` روی پورت **`3080`** سرور تنظیم شده است (`3080:3000`) تا با پورت `3000` یا `80` برنامه قبلی شما تداخل نداشته باشد.

---

### گام ۲: نصب Docker و Git (فقط اگر قبلاً نصب نشده‌اند)
چون روی سرور شما داکر در حال اجراست، نیازی به نصب مجدد داکر نیست؛ اما برای اطمینان از نصب بودن `git` دستور زیر را بزنید:

```bash
sudo apt-get update
sudo apt-get install -y git
```
*(اگر روی سرور جدیدی هستید که داکر ندارد، با دستور `curl -fsSL https://get.docker.com | sh` داکر را نصب کنید).*

---

### گام ۳: ایجاد پوشه مجزا و دریافت پروژه از GitHub
برای اینکه با پوشه `/var/www/app` تداخلی ایجاد نشود، پروژه را در پوشه مستقل `/var/www/karkardyar` کلون می‌کنیم:

```bash
# ۱. رفتن به مسیر /var/www
cd /var/www

# ۲. دریافت پروژه از گیت‌هاب در پوشه مستقل karkardyar
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git karkardyar

# ۳. ورود به پوشه پروژه
cd /var/www/karkardyar
```
*(به جای `YOUR_USERNAME/YOUR_REPO` آدرس مخزن گیت‌هاب خود را قرار دهید. اگر مخزن شما Private است، از توکن گیت‌هاب یا کلید SSH استفاده کنید).*

---

### گام ۴: ساخت پوشه دیتابیس و تنظیم پورت (اختیاری)
دیتابیس SQLite در پوشه `data` ذخیره می‌شود. با دستور زیر این پوشه را روی سرور بسازید:

```bash
mkdir -p /var/www/karkardyar/data
```

اگر می‌خواهید پورت برنامه غیر از `3080` باشد (مثلاً `4000`)، یک فایل `.env` بسازید:
```bash
echo "APP_PORT=3080" > .env
```

---

### گام ۵: ساخت ایمیج و اجرای دائمی برنامه با Docker Compose
حالا دستور زیر را اجرا کنید تا داکر ایمیج برنامه را بسازد و کانتینر را در پس‌زمینه راه‌اندازی کند:

```bash
docker compose up -d --build
```

**توضیح کارهایی که این دستور انجام می‌دهد:**
1. ایمیج `node:22-alpine` را دریافت کرده و وابستگی‌ها را نصب می‌کند.
2. فرانت‌اند React/Vite را بیلد (`npm run build`) می‌کند.
3. پوشه `/var/www/karkardyar/data` روی سرور را به پوشه `/app/data` داخل کانتینر متصل (Mount) می‌کند تا دیتابیس `karkard.sqlite` همیشه روی هارد سرور باقی بماند.
4. ساعت کانتینر را روی تهران (`TZ=Asia/Tehran`) تنظیم می‌کند.
5. با خاصیت `restart: unless-stopped`، در صورت ری‌استارت شدن VPS، برنامه را به‌صورت خودکار روشن می‌کند.

---

### گام ۶: باز کردن پورت در فایروال سرور (در صورت فعال بودن UFW)
اگر فایروال اوبونتو (`ufw`) روی سرور شما فعال است، پورت `3080` را باز کنید:

```bash
sudo ufw allow 3080/tcp
```

اکنون می‌توانید در مرورگر موبایل یا کامپیوتر خود آدرس زیر را باز کنید:
```text
http://YOUR_VPS_IP:3080
```

## چرخه توسعه و بروزرسانی پروژه از طریق GitHub

فایل‌های دیتابیس (`data/*.sqlite`) در `.gitignore` و `.dockerignore` قرار داده شده‌اند؛ بنابراین **هنگام آپدیت کردن کدها از گیت‌هاب، اطلاعات کارگران شما هرگز پاک یا بازنویسی نخواهد شد.**

هر زمان که در کدها تغییری ایجاد کردید و روی GitHub پوش (`git push`) زدید، برای آپدیت شدن برنامه روی VPS کافیست یکی از دو روش زیر را انجام دهید:

### روش اول: استفاده از اسکریپت خودکار `deploy.sh`
```bash
cd /var/www/karkardyar
chmod +x deploy.sh
./deploy.sh
```

### روش دوم: اجرای دستی دستورات آپدیت
```bash
cd /var/www/karkardyar
git pull origin main
docker compose up -d --build
```

## دستورات کاربردی مدیریت کانتینر و پشتیبان‌گیری

* **مشاهده وضعیت کانتینرها (هر دو برنامه):**
  ```bash
  docker ps
  ```
* **مشاهده لاگ‌های زنده کارکردیار:**
  ```bash
  cd /var/www/karkardyar
  docker compose logs -f
  ```
* **ری‌استارت کردن برنامه:**
  ```bash
  cd /var/www/karkardyar
  docker compose restart
  ```
* **توقف کامل برنامه (بدون پاک شدن دیتابیس):**
  ```bash
  cd /var/www/karkardyar
  docker compose down
  ```
* **گرفتن کپی پشتیبان دستی از دیتابیس روی سرور:**
  علاوه بر دکمه «پشتیبان‌گیری» در بالای محیط وب‌اپلیکیشن، می‌توانید روی سرور نیز از فایل دیتابیس کپی بگیرید:
  ```bash
  cp /var/www/karkardyar/data/karkard.sqlite ~/karkard-backup-$(date +%F).sqlite
  ```
