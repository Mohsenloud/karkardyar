# کارکردیار (KarkardYar) — سامانه شخصی ثبت کارکرد و حقوق کارگران

وب‌اپلیکیشن سبک، مدرن و واکنش‌گرا (بهینه‌شده برای موبایل) جهت ثبت حضور و غیاب، محاسبه خودکار کارکرد کارگران از تاریخ ورود تا امروز، مدیریت مساعده‌ها و صدور صورت‌حساب PDF و چاپی با دیتابیس **SQLite**.

---

## ویژگی‌های کلیدی
* **محاسبه هوشمند تا امروز:** محاسبه خودکار روزهای کارکرد و دستمزد از تاریخ استخدام تا امروز به همراه نمایش روزهای باقی‌مانده از قرارداد.
* **ویرایش سریع و بدون تاخیر (0ms):** تغییر وضعیت حضور/غیاب در تقویم یا کم و زیاد کردن روزهای کارکرد به‌صورت آنی.
* **مدیریت مساعده و پرداختی‌ها:** ثبت مساعده، تسویه حقوق و کسورات با کسر خودکار از مانده قابل پرداخت.
* **مدیریت چند پروژه با تفکیک حساب و رنگ‌بندی مجزا:** تعریف پروژه‌های مختلف (مثلاً پروژه الف، پروژه ب و...) با رنگ اختصاصی و محاسبه مستقل کارکرد و مانده حساب هر پروژه.
* **احراز هویت و قفل امنیتی سطح بالا (`scrypt` + `Salt`):** محافظت کامل از برنامه و تمام مسیرهای API با نام کاربری و رمز عبور اختصاصی، هش رمزنگاری‌شده `scrypt`، نشست‌های امن `SHA-256` و قفل خودکار ضد نفوذ (Brute-Force Protection).
* **صدور صورت‌حساب موبایلی، چاپی و PDF:** دریافت مستقیم فایل PDF استاندارد فارسی و چاپ تمیز فیش کارکرد هر کارگر.
* **دیتابیس سبک و دائمی SQLite (محافظت‌شده در برابر آپدیت):** ذخیره تمام اطلاعات در مسیر مستقل بیرون از پوشه گیت (`../karkardyar-data/karkard.sqlite`) با قابلیت دانلود فایل پشتیبان (Backup) از داخل برنامه.

## امنیت و نحوه تعریف نام کاربری و رمز عبور

این برنامه به یک سیستم احراز هویت رمزنگاری‌شده مجهز است تا هیچ فرد غیرمجازی نتواند به اطلاعات کارگران یا حساب‌های مالی دسترسی داشته باشد:

### ۱. معماری امنیتی
* **هش غیرقابل بازگشت با `scrypt` و `Salt` تصادفی:** رمز عبور شما هرگز به صورت متن ساده ذخیره نمی‌شود، بلکه با الگوریتم استاندارد `node:crypto scrypt` (`N=16384, r=8, p=1`) به همراه ۱۶ بایت Salt تصادفی یکتا هش شده و با تابع ضد حملات زمانی (`timingSafeEqual`) بررسی می‌شود.
* **توکن نشست هش‌شده (`SHA-256`):** پس از ورود، یک توکن تصادفی ۲۵۶ بیتی تولید شده و صرفاً هش `SHA-256` آن در جدول `auth_sessions` دیتابیس ذخیره می‌گردد.
* **محافظت در برابر حملات Brute-Force:** در صورت ۵ بار وارد کردن رمز اشتباه از یک IP، امکان ورود از آن IP به مدت **۱۵ دقیقه** به صورت خودکار قفل می‌شود.
* **حفاظت کامل از API و فایل‌های پشتیبان:** تمامی مسیرهای `/api/*` و لینک‌های دانلود دیتابیس بدون لاگین معتبر مسدود هستند.

### ۲. تعریف اولیه نام کاربری و رمز عبور
* **روش اول (از طریق محیط وب - پیشنهادی):** در اولین باری که آدرس برنامه را باز می‌کنید، صفحه **«تعریف نام کاربری و رمز عبور اولیه»** نمایش داده می‌شود. نام کاربری و رمز دلخواه خود (حداقل ۶ کاراکتر) را وارد کنید تا در دیتابیس امن سرور ثبت شود.
* **روش دوم (از طریق فایل `.env` روی سرور):** در صورت تمایل می‌توانید قبل از اجرای کانتینر، مقادیر اولیه را در فایل `.env` قرار دهید:
  ```env
  ADMIN_USERNAME=admin
  ADMIN_PASSWORD=YourStrongPassword123!
  ```

### ۳. تغییر نام کاربری یا رمز عبور از داخل برنامه
پس از ورود به برنامه، در نوار بالای صفحه روی دکمه **«امنیت و رمز»** (یا در تب **«کارگران و دیتابیس»** روی دکمه **«تغییر نام کاربری و رمز»**) کلیک کنید. با وارد کردن رمز عبور فعلی، می‌توانید نام کاربری و رمز عبور جدید خود را ثبت کنید یا از حساب خارج شوید.

### ۴. بازیابی رمز عبور در صورت فراموشی (از طریق SSH روی سرور VPS)
اگر زمانی رمز عبور خود را فراموش کردید، بدون اینکه هیچ‌یک از اطلاعات کارگران یا پروژه‌ها پاک شود، می‌توانید با اجرای دستور زیر روی سرور، رمز قبلی را ریست کنید تا برنامه مجدداً صفحه «تعریف نام کاربری و رمز عبور اولیه» را به شما نشان دهد:

```bash
cd /var/www/karkardyar
docker compose exec karkardyar node -e "
const { DatabaseSync } = require('node:sqlite');
const db = new DatabaseSync('/app/data/karkard.sqlite');
db.exec(\"DELETE FROM app_meta WHERE key IN ('admin_username','admin_password_hash','admin_password_salt'); DELETE FROM auth_sessions;\");
console.log('Credentials reset successfully! Open the web app to set a new username and password.');
"
```

## راهنمای جامع نصب و راه‌اندازی با Docker روی سرور (VPS)

این راهنما به گونه‌ای تنظیم شده است که اگر روی سرور شما در مسیر `/var/www/app` برنامه دیگری با داکر در حال اجرا باشد، **هیچ‌گونه تداخل پورت، شبکه یا فایلی** با آن ایجاد نشود.

---

### گام ۱: اتصال به سرور و بررسی وضعیت فعلی
ابتدا با SSH به سرور خود متصل شوید و کانتینرهای در حال اجرا را بررسی کنید تا ببینید چه پورت‌هایی اشغال شده‌اند:

```bash
docker ps
```
> **نکته:** این برنامه به‌صورت پیش‌فرض در فایل `docker-compose.yml` روی پورت **`3080`** سرور تنظیم شده است (`3080:3000`) تا با پورت `3000` یا `80` برنامه قبلی شما تداخل نداشته باشد.

---

### گام ۲: نصب Docker و Git (فقط اگر قبلاً نصب نشده‌اند)
چون روی سرور شما داکر در حال اجراست، نیازی به نصب مجدد داکر نیست؛ اما برای اطمینان از نصب بودن `git` دستور زیر را بزنید:

```bash
sudo apt-get update
sudo apt-get install -y git
```
*(اگر روی سرور جدیدی هستید که داکر ندارد، با دستور `curl -fsSL https://get.docker.com | sh` داکر را نصب کنید).*

---

### گام ۳: ایجاد پوشه مجزا و دریافت پروژه از GitHub
برای اینکه با پوشه `/var/www/app` تداخلی ایجاد نشود، پروژه را در پوشه مستقل `/var/www/karkardyar` کلون می‌کنیم:

```bash
# ۱. رفتن به مسیر /var/www
cd /var/www

# ۲. دریافت پروژه از گیت‌هاب در پوشه مستقل karkardyar
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git karkardyar

# ۳. ورود به پوشه پروژه
cd /var/www/karkardyar
```
*(به جای `YOUR_USERNAME/YOUR_REPO` آدرس مخزن گیت‌هاب خود را قرار دهید. اگر مخزن شما Private است، از توکن گیت‌هاب یا کلید SSH استفاده کنید).*

---

### گام ۴: ساخت پوشه امن دیتابیس (خارج از پوشه گیت) و تنظیم پورت
برای اینکه هنگام آپدیت کدهای برنامه از گیت‌هاب (`git pull`) هیچ‌گاه دیتابیس سرور جایگزین یا پاک نشود، فایل دیتابیس در پوشه مستقل `/var/www/karkardyar-data` (بیرون از پوشه کدهای گیت) نگهداری می‌شود:

```bash
mkdir -p /var/www/karkardyar-data
```

اگر می‌خواهید پورت برنامه غیر از `3080` باشد (مثلاً `4000`)، یک فایل `.env` بسازید:
```bash
echo "APP_PORT=3080" > .env
```

---

### گام ۵: ساخت ایمیج و اجرای دائمی برنامه با Docker Compose
حالا دستور زیر را اجرا کنید تا داکر ایمیج برنامه را بسازد و کانتینر را در پس‌زمینه راه‌اندازی کند:

```bash
docker compose up -d --build
```

**توضیح کارهایی که این دستور انجام می‌دهد:**
1. ایمیج `node:22-alpine` را دریافت کرده و وابستگی‌ها را نصب می‌کند.
2. فرانت‌اند React/Vite را بیلد (`npm run build`) می‌کند.
3. پوشه `/var/www/karkardyar-data` روی سرور (خارج از پوشه گیت) را به پوشه `/app/data` داخل کانتینر متصل (Mount) می‌کند تا دیتابیس `karkard.sqlite` (شامل اطلاعات پروژه‌ها، کارگران و رمز عبور شما) همیشه مستقل از کدهای برنامه باقی بماند.
4. اگر از قبل دیتابیسی در پوشه قدیمی `/var/www/karkardyar/data/karkard.sqlite` داشته باشید، سرور در اولین اجرا به‌صورت خودکار آن را به `/var/www/karkardyar-data/karkard.sqlite` منتقل می‌کند تا هیچ اطلاعاتی از دست نرود.
5. با خاصیت `restart: unless-stopped`، در صورت ری‌استارت شدن VPS، برنامه را به‌صورت خودکار روشن می‌کند.

---

### گام ۶: باز کردن پورت در فایروال سرور (در صورت فعال بودن UFW)
اگر فایروال اوبونتو (`ufw`) روی سرور شما فعال است، پورت `3080` را باز کنید:

```bash
sudo ufw allow 3080/tcp
```

اکنون می‌توانید در مرورگر موبایل یا کامپیوتر خود آدرس زیر را باز کنید:
```text
http://YOUR_VPS_IP:3080
```

## چرخه توسعه و بروزرسانی امن کدها از طریق GitHub (بدون تغییر در دیتابیس)

معماری ذخیره‌سازی برنامه به گونه‌ای طراحی شده است که:
1. در محیط توسعه (AI Studio)، دیتابیس آزمایشی در مسیر موقت سیستم‌عامل (`/tmp`) ساخته می‌شود؛ بنابراین **هیچ فایل `.sqlite` وارد مخزن GitHub شما نمی‌شود.**
2. روی سرور VPS، دیتابیس اصلی شما در مسیر `/var/www/karkardyar-data/karkard.sqlite` (خارج از پوشه گیت `/var/www/karkardyar`) قرار دارد.
3. اسکریپت `deploy.sh` قبل از هر بار دریافت کد جدید، یک نسخه پشتیبان خودکار با تاریخ و ساعت در پوشه `/var/www/karkardyar-backups` ذخیره می‌کند.

هر زمان که در کدها تغییری ایجاد کردید و روی GitHub پوش (`git push`) زدید، برای آپدیت شدن کدهای برنامه روی VPS کافیست دستور زیر را اجرا کنید:

### روش پیشنهادی: استفاده از اسکریپت محافظت‌شده `deploy.sh`
```bash
cd /var/www/karkardyar
chmod +x deploy.sh
./deploy.sh
```

### روش دوم: اجرای دستی دستورات آپدیت
```bash
cd /var/www/karkardyar
git pull origin main
docker compose up -d --build
```

## دستورات کاربردی مدیریت کانتینر و پشتیبان‌گیری

* **مشاهده وضعیت کانتینرها (هر دو برنامه):**
  ```bash
  docker ps
  ```
* **مشاهده لاگ‌های زنده کارکردیار:**
  ```bash
  cd /var/www/karkardyar
  docker compose logs -f
  ```
* **ری‌استارت کردن برنامه:**
  ```bash
  cd /var/www/karkardyar
  docker compose restart
  ```
* **توقف کامل برنامه (بدون پاک شدن دیتابیس):**
  ```bash
  cd /var/www/karkardyar
  docker compose down
  ```
* **گرفتن کپی پشتیبان دستی از دیتابیس روی سرور:**
  علاوه بر دکمه «پشتیبان SQLite» در بالای محیط وب‌اپلیکیشن، می‌توانید روی سرور نیز از فایل دیتابیس کپی بگیرید:
  ```bash
  cp /var/www/karkardyar-data/karkard.sqlite ~/karkard-backup-$(date +%F).sqlite
  ```
